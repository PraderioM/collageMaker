This code can be used in order to make collages out of whatever set of whatever picture you have out of whatever set of pictures you have.

### image_downloader
By running "python -m image_downloader" in your terminal you will be executing this file. As a result you will be asked a series of questions
that will result on using a bing app to scrap the web for pictures following a search of your choice and storing them in a folder of your choice.

### video_frame_extractor
By running "python -m video_frame_extractor" in your terminal you will be executing this file. As a result you will be asked a series of questions
that will result on extracting frames from a video of your choice and storing them on a folder of your choice.

### remove_duplicates
By running "python -m remove_duplicates" in your terminal you will be executing this file. As a result you will be asked a series of questions
that will result in pictures with the same hash code in a given folder being removed.

### main
By running "python -m main" in your terminal you will be executing this file. As a result you will be asked a series of questions prompting 
you to enter the path to an image and to a folder full of images (among others). After you have answered all the questions the program will use the
images in the specified folder in order to recreate the specified image. The result will be stored in a path of your choice.
